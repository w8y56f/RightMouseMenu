# RightMouseMenu

[简体中文](README.md)

macOS 15+ Finder contextual menu utility. The app has a menu bar control and settings for New File, development tools, and utilities.

Run from the project directory:

```sh
bash Scripts/run.sh
```

To debug in Xcode, open `RightMouseMenu.xcodeproj` and run the `RightMouseMenu` scheme. The run script registers the Finder extension and launches the bundled app. In RightMouseMenu, use Permissions → Open Login Items & Extensions to enable it. If you are updating from an older build, enable the new Finder extension and relaunch Finder if it still shows the old menu.

Use Permissions → Request Finder Automation to grant access for File Information. New Terminal windows and iTerm2 request Automation access on first use. Terminal tabs use the built-in New Terminal Tab at Folder service. Tabby windows and tabs use its command-line launcher.

The project file is generated by `Scripts/generate_project.py`; edit that script if targets or build resources change.
